# ✅ Diferencias por tipo de instrumento

### 🎻 Guitarra acústica

* Enfoque en: **puente, saddle, cejuela, altura de cuerdas**
* Mucho uso de: limas de hueso, bloques de lijado, calibradores

### 🎸 Electroacústica

* Todo lo anterior +
* **Soldador, multímetro, preamp, jack, piezo**

### 🎸 Bajo

* Llaves Allen de mayor torque
* Galgas más gruesas
* Niveladores largos de trastes
* Trabajo fuerte de puente y quintaje
